CLEAN-ROOM PLATFORM REFERENCE

PlatformDocs: Platform-Inherited Binary Formats

PlatformDocs documents binary container, filesystem, executable, relocatable module, firmware, and OS metadata formats inherited directly from 11 hardware and operating system platforms. Every specification is written to a clean-room 6-section standard with exact hex offsets, fixed-width types, decoding formulas, bounds rules, and parser pseudocode.

Strict Scope Boundary: Only platform-mandated, firmware-loaded, and OS-defined formats are included. All title-specific assets, third-party middleware files, and studio engine formats are excluded.
