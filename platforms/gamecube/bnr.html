GameCube Disc Banner (opening.bnr)

Platform UI Metadata · Nintendo GameCube IPL

1. Identification & Scope

When a GameCube disc is inserted with the IPL menu active, the Boot ROM reads opening.bnr from the root of fst.bin. Two variants exist, distinguished solely by the 4-byte ASCII magic at offset 0x0000 and the resulting count of 320-byte description records:

  • BNR1 (0x424E5231): Single-language variant used on NTSC-U and NTSC-J discs (and single-language releases). Total file size: 0x1960 (6,496 bytes).
  • BNR2 (0x424E5232): Six-language PAL/European variant providing slots for English, German, French, Spanish, Italian, and Dutch. Total file size: 0x1FA0 (8,096 bytes).
  • Endianness: All 16-bit icon texels in the 96×32 RGB5A3 image buffer are big-endian (u16be), matching the Flipper GX texture pipeline.

3. Flags, Enums & Decoding Formulas

RGB5A3 4×4 Tile Addressing

The 96 × 32 icon is partitioned into 24 × 8 tiles of 4 × 4 pixels each, ordered left-to-right then top-to-bottom. Each tile occupies 16 × 2 = 32 bytes (one GX cache line):

tiles_x = 96 / 4 = 24
tiles_y = 32 / 4 = 8
// For tile (tx, ty) and local texel (px, py) with 0 <= px, py < 4:
u16_index = ((ty * 24 + tx) * 16) + (py * 4 + px)
byte_off  = 0x0020 + u16_index * 2
pixel_x   = tx * 4 + px
pixel_y   = ty * 4 + py

RGB5A3 Pixel Decoding (Bit 15 Mode Selector)

Each big-endian 16-bit texel v = read_u16be(byte_off) encodes either opaque 5-bit RGB or translucent 3-bit alpha + 4-bit RGB depending on bit 15:

  • Bit 15 = 1 ((v & 0x8000) != 0) — Opaque RGB555:
    • r5 = (v >> 10) & 0x1F → R = (r5 << 3) | (r5 >> 2)
    • g5 = (v >> 5) & 0x1F → G = (g5 << 3) | (g5 >> 2)
    • b5 = v & 0x1F → B = (b5 << 3) | (b5 >> 2)
    • A = 255
  • Bit 15 = 0 ((v & 0x8000) == 0) — Translucent ARGB3444:
    • a3 = (v >> 12) & 0x07 → A = (a3 << 5) | (a3 << 2) | (a3 >> 1)
    • r4 = (v >> 8) & 0x0F → R = (r4 << 4) | r4
    • g4 = (v >> 4) & 0x0F → G = (g4 << 4) | g4
    • b4 = v & 0x0F → B = (b4 << 4) | b4

BNR2 Language Slot Mapping

The PAL IPL selects the BNR2 slot index 0..5 according to the console SRAM language setting: 0 = English, 1 = German, 2 = French, 3 = Spanish, 4 = Italian, 5 = Dutch.

4. Edge Cases & Loader/Parser Rules

  • Strict File Size Checks: Validate exact minimum size against the magic header: 0x1960 bytes for BNR1 and 0x1FA0 bytes for BNR2. Reject truncated files before decoding icon tiles or description slots.
  • Text Character Encoding by Region: BNR1 on Japanese discs (bi2.bin CountryCode == 0) encodes strings in Shift-JIS (CP932), whereas NTSC-U and PAL discs use single-byte Windows-1252 / ISO-8859-1. Always treat the disc's region/CountryCode as context when decoding bytes >= 0x80.
  • Missing NUL Terminators & Multiline Strings: Strings may fill their entire fixed buffer (32, 64, or 128 bytes) without a trailing 0x00, or include embedded 0x0A (\n) characters inside LongTitle, LongMaker, and Description. Bound string reads to the field capacity and stop at the first 0x00.
  • Duplicate/Empty Slots in BNR2: Some PAL discs repeat the English string in unlocalized slots or leave unused slots empty (starting with 0x00); fall back to slot 0 (English) if a selected language slot is empty.

5. Step-by-Step Parser Pseudocode

function decode_rgb5a3_pixel(v):
    if (v & 0x8000) != 0:
        r5 = (v >> 10) & 0x1F
        g5 = (v >> 5)  & 0x1F
        b5 = v & 0x1F
        return ((r5 << 3) | (r5 >> 2), (g5 << 3) | (g5 >> 2), (b5 << 3) | (b5 >> 2), 255)
    else:
        a3 = (v >> 12) & 0x07
        r4 = (v >> 8)  & 0x0F
        g4 = (v >> 4)  & 0x0F
        b4 = v & 0x0F
        return ((r4 << 4) | r4, (g4 << 4) | g4, (b4 << 4) | b4, (a3 << 5) | (a3 << 2) | (a3 >> 1))

function parse_opening_bnr(data, encoding = "latin1"):
    assert len(data) >= 0x1960
    magic = read_ascii(data, 0x0000, 4)
    if magic == "BNR1":
        slot_count = 1
        assert len(data) >= 0x1960
    elif magic == "BNR2":
        slot_count = 6
        assert len(data) >= 0x1FA0
    else:
        error("Invalid banner magic; expected BNR1 or BNR2")

    // Decode 96x32 RGBA8888 icon from 24x8 tiles of 4x4 RGB5A3 texels
    rgba = allocate_rgba_image(96, 32)
    pos = 0x0020
    for ty in 0 .. 7:
        for tx in 0 .. 23:
            for py in 0 .. 3:
                for px in 0 .. 3:
                    v = read_u16be(data, pos)
                    pos += 2
                    rgba.set_pixel(tx * 4 + px, ty * 4 + py, decode_rgb5a3_pixel(v))

    slots = []
    for i in 0 .. slot_count - 1:
        base = 0x1820 + i * 0x0140
        slots.append({
            short_title: decode_cstr(data, base + 0x0000, 32,  encoding),
            short_maker: decode_cstr(data, base + 0x0020, 32,  encoding),
            long_title:  decode_cstr(data, base + 0x0040, 64,  encoding),
            long_maker:  decode_cstr(data, base + 0x0080, 64,  encoding),
            description: decode_cstr(data, base + 0x00C0, 128, encoding)
        })

    return { magic, icon_rgba: rgba, descriptions: slots }

6. Provenance & Confidence

Text encoding is not self-described in opening.bnr: Neither BNR1 nor BNR2 embeds a charset flag. Correct decoding of non-ASCII characters (Shift-JIS vs. Windows-1252) relies on the disc's bi2.bin CountryCode or boot.bin region character.

  • Confirmed Hardware/IPL Spec: Magic values BNR1/BNR2, total byte lengths (0x1960 / 0x1FA0), 96×32 4×4 tiled GX_TF_RGB5A3 pixel encoding, and 320-byte slot field boundaries are invariant across retail GameCube IPL versions.
  • Reserved Padding: Bytes 0x0004–0x001F (28 bytes) are reserved padding (zeroed in standard banners) and ignored by the IPL banner parser.
