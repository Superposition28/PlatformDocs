GameCube Disc Image (.iso / .gcm) & FST

Platform Container & Filesystem · Nintendo GameCube

1. Identification & Scope

GameCube optical disc images store raw 2048-byte user sectors without an ISO-9660 or UDF volume descriptor. Both .iso and .gcm (GameCube Master) refer to the exact same unencrypted byte stream; a full single-layer retail disc image measures exactly 1,459,978,240 bytes (0x57058000 bytes, 712,880 sectors).

  • Primary Magic: Offset 0x001C holds big-endian 0xC2339F3D (bytes C2 33 9F 3D). Note that Wii discs place their magic 0x5D1C9EA3 at 0x0018 instead, leaving 0x001C as 0x00000000.
  • Console ID Byte: Offset 0x0000 is an ASCII prefix character—typically 'G' (0x47, retail GameCube), 'D' (0x44, demo/kiosk), 'P' (0x50, promotional), or 'U' (0x55, utility/loader disc).
  • Endianness: All numeric fields in boot.bin, bi2.bin, the Apploader header, and fst.bin are strictly big-endian.

fst.bin Entry Record (12 bytes per entry, followed by String Table at N * 12)
Offset Size Type Field Description
0x00 0x01 u8 IsDirectory High byte of first u32be: 0x00 = File, 0x01 = Directory (including root entry 0).
0x01 0x03 u24be NameOffset 24-bit byte offset into the String Table (located at fst_start + total_entries * 12). Ignored (0) for root entry 0.
0x04 0x04 u32be FileOffset / ParentIndex If File: absolute byte offset in disc image. If Directory: 0-based FST index of parent directory (0 for root and top-level dirs).
0x08 0x04 u32be FileLength / NextIndex If File: byte length of file. If Directory: exclusive end FST index (TotalEntries for root entry 0).

3. Flags, Enums & Decoding Formulas

FST Entry Bit-Packing

Each 12-byte FST entry packs its entry type and string-table offset into a single u32be word at entry offset 0x00:

word0        = read_u32be(entry + 0x00)
is_directory = ((word0 >> 24) & 0xFF) != 0   // bit 24: 0x01 = directory, 0x00 = file
name_offset  = word0 & 0x00FFFFFF             // bits 0..23: relative to string_table_base

Because root entry 0 is always a directory whose 0x08 field holds TotalEntries (N), the string table always begins at:

string_table_base = fst_offset + (total_entries * 12)

Directory Traversal Invariant

The FST is stored in pre-order depth-first sequence. For any directory entry at index i with next_idx = entry[i].NextIndex:

  • Immediate children and nested descendants occupy indices i + 1 through next_idx - 1.
  • When iterating directory i's direct children starting at child = i + 1, if child is a file, advance to child + 1; if child is a directory, jump directly over its subtree to entry[child].NextIndex.

Region / Country Code Enums

  • boot.bin[0x0003] (GameCode region suffix): 'E' (USA/NTSC), 'P' (Europe/PAL), 'J' (Japan/NTSC), 'K' (Korea), 'W' (Taiwan), 'X'/'Y'/'D'/'F'/'S'/'I' (localized European variants).
  • bi2.bin[0x0018] (CountryCode): 0 = Japan, 1 = USA, 2 = Europe/PAL.

4. Edge Cases & Loader/Parser Rules

  • Disc Bounds & Scrubbed Images: Retail full-size dumps are 0x57058000 bytes, whereas trimmed images end after the highest referenced file sector. Always validate DolOffset, FstOffset + FstSize, and every FST file's FileOffset + FileLength <= image_size before reading.
  • FST Bounds & Cycles: Verify FstSize >= 12, TotalEntries >= 1, and TotalEntries * 12 <= FstSize. For every directory entry i, enforce i < NextIndex <= TotalEntries so malformed or cyclic FSTs cannot cause infinite recursion.
  • 24-bit String Offset Bounds: Enforce string_table_base + name_offset < fst_offset + FstSize and search for a NUL terminator strictly within fst_offset + FstSize. Reject names containing path separators ('/', '\') or ".." when extracting to a host filesystem.
  • Generalized Apploader & Boot Loader Mapping: A clean-room parser does not execute the PowerPC Apploader binary. Instead, it locates the main .dol via boot.bin[0x0420] and fst.bin via boot.bin[0x0424..0x0428], and models the BS2/Apploader memory state using bi2.bin[0x0444] (SimulatedMemorySize, typically 24 MiB) and boot.bin[0x042C] (FstMaxSize).
  • System File Exclusion: boot.bin, bi2.bin, Apploader, main .dol, and fst.bin do not appear as entries inside fst.bin; extractors commonly materialize them as synthetic system files alongside the FST tree.
  • Compressed Wrappers Excluded: Formats such as .gcz, .ciso, and .rvz wrap or re-pack raw sectors with external compression headers and must be decompressed to raw 2048-byte-sector layout before applying this specification.

5. Step-by-Step Parser Pseudocode

struct FstNode:
    is_dir: bool
    name: string
    disc_offset: u32    // valid if !is_dir
    length: u32         // valid if !is_dir
    parent_idx: u32     // valid if is_dir
    next_idx: u32       // valid if is_dir

function parse_gamecube_disc(stream, image_size):
    assert image_size >= 0x2460
    boot = read_bytes(stream, 0x0000, 0x0440)
    bi2  = read_bytes(stream, 0x0440, 0x2000)

    magic = read_u32be(boot, 0x001C)
    assert magic == 0xC2339F3D, "Not a GameCube disc image"

    game_code  = read_ascii(boot, 0x0000, 4)
    maker_code = read_ascii(boot, 0x0004, 2)
    disc_id    = boot[0x0006]
    version    = boot[0x0007]
    game_name  = read_cstr(boot, 0x0020, 0x3E0)

    dol_offset   = read_u32be(boot, 0x0420)
    fst_offset   = read_u32be(boot, 0x0424)
    fst_size     = read_u32be(boot, 0x0428)
    fst_max_size = read_u32be(boot, 0x042C)
    country_code = read_u32be(bi2,  0x0018)

    assert dol_offset >= 0x2460 and dol_offset + 0x0100 <= image_size
    assert fst_offset >= 0x2460 and fst_size >= 12
    assert fst_offset + fst_size <= image_size

    app_hdr = read_bytes(stream, 0x2440, 0x20)
    app_size    = read_u32be(app_hdr, 0x14)
    app_trailer = read_u32be(app_hdr, 0x18)
    assert 0x2460 + app_size + app_trailer <= image_size

    fst_buf = read_bytes(stream, fst_offset, fst_size)
    root_word0 = read_u32be(fst_buf, 0x00)
    assert ((root_word0 >> 24) & 0xFF) == 1, "FST entry 0 must be root directory"

    total_entries = read_u32be(fst_buf, 0x08)
    assert total_entries >= 1 and total_entries * 12 <= fst_size

    str_table_off = total_entries * 12
    nodes = []
    for i in 0 .. total_entries - 1:
        base = i * 12
        word0 = read_u32be(fst_buf, base + 0x00)
        word1 = read_u32be(fst_buf, base + 0x04)
        word2 = read_u32be(fst_buf, base + 0x08)

        is_dir = ((word0 >> 24) & 0xFF) != 0
        name_off = word0 & 0x00FFFFFF
        if i == 0:
            name = ""
        else:
            assert str_table_off + name_off < fst_size
            name = read_cstr(fst_buf, str_table_off + name_off, fst_size - (str_table_off + name_off))

        if is_dir:
            assert word2 > i and word2 <= total_entries, "Invalid directory NextIndex"
            nodes.append(FstNode(true, name, 0, 0, word1, word2))
        else:
            assert word1 + word2 <= image_size, "File extends past disc image"
            nodes.append(FstNode(false, name, word1, word2, 0, 0))

    return { game_code, maker_code, disc_id, version, game_name, country_code, dol_offset, fst_max_size, nodes }

function build_directory_paths(nodes, dir_idx = 0, prefix = ""):
    results = []
    idx = dir_idx + 1
    end_idx = nodes[dir_idx].next_idx
    while idx < end_idx:
        node = nodes[idx]
        rel_path = (prefix == "") ? node.name : (prefix + "/" + node.name)
        if node.is_dir:
            results.extend(build_directory_paths(nodes, idx, rel_path))
            idx = node.next_idx
        else:
            results.append((rel_path, node.disc_offset, node.length))
            idx += 1
    return results

6. Provenance & Confidence

SDK-revision & reserved fields: Fields at boot.bin[0x0430..0x043F] (UserPosition, UserLength, Unknown438) and bi2.bin[0x045C] vary across Dolphin SDK revisions and mastering tools (`makedisk`). Parsers should inspect them diagnostically rather than hardcoding non-zero values.

  • Confirmed Hardware/IPL Specs: Fixed offsets 0x0000 (boot.bin), 0x0440 (bi2.bin), 0x2440 (Apploader header), magic 0xC2339F3D at 0x001C, and 24-bit FST string offsets with bit-24 directory flag are invariant across retail GameCube discs.
  • SDK-Revision-Dependent: Apploader build date strings, exact Apploader entry points (0x81200000–0x81200258+), AudioStreaming buffer defaults, and debug monitor offsets (0x0400–0x0407, zeroed on retail discs).
