GameCube Relocatable Module (.rel)

Platform Dynamic Module · Nintendo GameCube / Dolphin OS

Big-endian PowerPC dynamically linked module format (header versions 1, 2, and 3) loaded at runtime by Dolphin OS OSLink / OSLinkFixed, containing a section table, per-module import descriptors, and stream-encoded relocation records.

1. Identification & Scope

Dolphin OS provides dynamic code loading via .rel modules generated by makerel from linked ELF objects. Each module carries a unique positive numeric Id (Id == 0 is reserved for the static boot .dol) and resolves cross-module calls and data references without storing ASCII symbol tables inside the .rel itself.

  • Header Versions: Version 1 (0x40 bytes), Version 2 (0x48 bytes, adds alignment constraints), and Version 3 (0x4C bytes, adds FixSize for OSLinkFixed).
  • Endianness: All headers, section info entries, import descriptors, relocation records, and patched PowerPC instructions/data are big-endian.

2. Binary Layout Tables

OSModuleHeader (v1: 0x00–0x3F, v2: +0x08, v3: +0x04)
Offset Size Type Field Description
0x00 0x04 u32be Id Unique non-zero module identifier (0 is reserved for the main .dol).
0x04 0x04 u32be Next Runtime linked-list pointer (0 on disk).
0x08 0x04 u32be Prev Runtime linked-list pointer (0 on disk).
0x0C 0x04 u32be NumSections Number of 8-byte entries in the Section Info Table.
0x10 0x04 u32be SectionInfoOffset File offset to the Section Info Table.
0x14 0x04 u32be NameOffset Offset into external/loaded module name string table (0 if stripped).
0x18 0x04 u32be NameSize Byte length of the module name string (0 if stripped).
0x1C 0x04 u32be Version Header format version: 1, 2, or 3.
0x20 0x04 u32be BssSize Total byte size of the module's zero-initialized .bss buffer.
0x24 0x04 u32be RelOffset File offset to the start of the relocation stream area.
0x28 0x04 u32be ImpOffset File offset to the Import Table (OSImportInfo array).
0x2C 0x04 u32be ImpSize Byte size of the Import Table (num_imports * 8).
0x30 0x01 u8 PrologSection Section index containing _prolog initialization function (0 if none).
0x31 0x01 u8 EpilogSection Section index containing _epilog teardown function (0 if none).
0x32 0x01 u8 UnresolvedSection Section index containing _unresolved fallback handler (0 if none).
0x33 0x01 u8 BssSection Runtime-populated index of the BSS section (0 on disk).
0x34 0x04 u32be PrologOffset Byte offset of _prolog within PrologSection.
0x38 0x04 u32be EpilogOffset Byte offset of _epilog within EpilogSection.
0x3C 0x04 u32be UnresolvedOffset Byte offset of _unresolved within UnresolvedSection.
0x40 0x04 u32be Align [v2+] Required byte alignment for module buffer (power of 2, typically 0x20).
0x44 0x04 u32be BssAlign [v2+] Required byte alignment for BSS buffer (power of 2, typically 0x20).
0x48 0x04 u32be FixSize [v3 only] Size in bytes of the fixed portion of the module retained by OSLinkFixed after discarding relocations.
Section Info Entry (OSSectionInfo, 8 bytes × NumSections at SectionInfoOffset)
Offset Size Type Field Description
0x00 0x04 u32be OffsetAndFlags Bit 0: executable flag (1 = code). Bits 1..31 (& ~1): file offset of section payload, or 0 for BSS / null section.
0x04 0x04 u32be Size Byte size of section. If Offset == 0 and Size > 0, this slot represents the BSS section.
Import Entry (OSImportInfo, 8 bytes × ImpSize / 8 at ImpOffset)
Offset Size Type Field Description
0x00 0x04 u32be ModuleId Target module providing the symbol addresses: 0 = main .dol, Id = self, or another .rel module ID.
0x04 0x04 u32be RelocationOffset File offset (from start of .rel) where the OSRel stream for this module begins.
Relocation Record (OSRel, 8 bytes per record, terminated by R_DOLPHIN_END)
Offset Size Type Field Description
0x00 0x02 u16be Offset Unsigned byte delta added to the current patch address P before applying Type.
0x02 0x01 u8 Type Relocation opcode (R_PPC_* patch type or R_DOLPHIN_* stream control).
0x03 0x01 u8 Section For R_DOLPHIN_SECTION: section index in this module. For R_PPC_*: target section index in imported ModuleId.
0x04 0x04 u32be Addend Target offset within ModuleId's Section (or absolute RAM address when ModuleId == 0).

3. Flags, Enums & Decoding Formulas

Section Info Bitmask

raw_offset  = read_u32be(sec_entry + 0x00)
is_exec     = (raw_offset & 0x00000001) != 0
file_offset = raw_offset & 0xFFFFFFFE
sec_size    = read_u32be(sec_entry + 0x04)
is_bss      = (file_offset == 0) and (sec_size > 0)
is_null     = (file_offset == 0) and (sec_size == 0)

PowerPC & Dolphin Relocation Types (OSRel.Type)

Let P be the current virtual RAM address being patched (updated by P += Offset on each non-control record), and let S be the resolved virtual target address: S = Addend if ModuleId == 0, otherwise S = target_module.section_base[Section] + Addend.

OSRel.Type Relocation Opcodes
Code (Dec / Hex) Size Mnemonic Target Formula / Semantics
0 (0x00) — R_PPC_NONE — No write; advances P += Offset.
1 (0x01) 32-bit R_PPC_ADDR32 word *u32be(P) = S
2 (0x02) 24-bit R_PPC_ADDR24 b/bl *u32be(P) = (*u32be(P) & ~0x03FFFFFC) | (S & 0x03FFFFFC)
3 (0x03) 16-bit R_PPC_ADDR16 half *u16be(P) = S & 0xFFFF
4 (0x04) 16-bit R_PPC_ADDR16_LO half *u16be(P) = S & 0xFFFF
5 (0x05) 16-bit R_PPC_ADDR16_HI half *u16be(P) = (S >> 16) & 0xFFFF
6 (0x06) 16-bit R_PPC_ADDR16_HA half *u16be(P) = ((S + 0x8000) >> 16) & 0xFFFF (high-adjusted for signed lo)
7 (0x07) 14-bit R_PPC_ADDR14 bc *u32be(P) = (*u32be(P) & ~0x0000FFFC) | (S & 0x0000FFFC)
8 / 9 (0x08/0x09) 14-bit R_PPC_ADDR14_BRTAKEN / BRNTAKEN bc Same 14-bit address encoding as R_PPC_ADDR14 (branch-prediction variants).
10 (0x0A) 24-bit R_PPC_REL24 b/bl *u32be(P) = (*u32be(P) & ~0x03FFFFFC) | ((S - P) & 0x03FFFFFC)
11 (0x0B) 14-bit R_PPC_REL14 bc *u32be(P) = (*u32be(P) & ~0x0000FFFC) | ((S - P) & 0x0000FFFC)
12 / 13 (0x0C/0x0D) 14-bit R_PPC_REL14_BRTAKEN / BRNTAKEN bc Same 14-bit relative encoding as R_PPC_REL14.
201 (0xC9) — R_DOLPHIN_NOP control Advances cursor P += Offset without patching (bridges gaps > 0xFFFF).
202 (0xCA) — R_DOLPHIN_SECTION control Resets cursor P = current_module.section_base[Section] (ignores Offset).
203 (0xCB) — R_DOLPHIN_END control Ends relocation stream for the current OSImportInfo entry.
204 (0xCC) — R_DOLPHIN_MRKREF control Reference marker opcode (no patch applied in standard OSLink).

4. Edge Cases & Loader/Parser Rules

  • Header Size by Version: Check Version at 0x1C before reading past 0x40: v1 uses 0x40 bytes (default alignment 0x20 in OSLink), v2 uses 0x48 bytes (explicit Align and BssAlign), and v3 uses 0x4C bytes (adds FixSize).
  • Section 0 Convention & BSS Detection: Section index 0 is always a null slot (Offset == 0, Size == 0). A single later slot has (Offset & ~1) == 0 and Size > 0, designating the BSS section whose virtual base resides in the caller-supplied BSS buffer (of size BssSize), not inside the loaded .rel file image.
  • Import Table & Unresolved References: Validate (ImpSize % 8) == 0 and ImpOffset + ImpSize <= file_size. When a .rel references another .rel (ModuleId != 0 and ModuleId != self.Id) that is not yet loaded, OSLink leaves those sites patched/redirected to _unresolved or resolves them when the target module links later.
  • Relocation Stream Bounds: Each OSImportInfo.RelocationOffset must lie within [RelOffset, file_size) and read aligned 8-byte records up to R_DOLPHIN_END without crossing EOF.
  • Patch Target Bounds & Alignment: Verify the active section set by R_DOLPHIN_SECTION satisfies Section < NumSections and is non-null/non-BSS, and verify each patched P lies within that section's allocated byte range.
  • Generalized Loader Mapping: On PowerPC hardware, OSLink flushes data cache (DCFlushRange) and invalidates instruction cache (ICInvalidateRange) after patching executable sections, then invokes _prolog() if PrologSection != 0. Static analysis tools only need to map sections into a virtual buffer, allocate BssSize bytes zero-initialized, and apply the relocation stream.

5. Step-by-Step Parser Pseudocode

function parse_rel_header(stream, file_size):
    assert file_size >= 0x40
    hdr = read_bytes(stream, 0x00, min(0x4C, file_size))

    id       = read_u32be(hdr, 0x00)
    num_sec  = read_u32be(hdr, 0x0C)
    sec_off  = read_u32be(hdr, 0x10)
    version  = read_u32be(hdr, 0x1C)
    bss_size = read_u32be(hdr, 0x20)
    rel_off  = read_u32be(hdr, 0x24)
    imp_off  = read_u32be(hdr, 0x28)
    imp_size = read_u32be(hdr, 0x2C)

    assert id > 0 and version in {1, 2, 3}
    hdr_size = (version == 1) ? 0x40 : ((version == 2) ? 0x48 : 0x4C)
    assert file_size >= hdr_size

    align     = (version >= 2) ? read_u32be(hdr, 0x40) : 0x20
    bss_align = (version >= 2) ? read_u32be(hdr, 0x44) : 0x20
    fix_size  = (version >= 3) ? read_u32be(hdr, 0x48) : file_size

    assert sec_off + num_sec * 8 <= file_size
    assert (imp_size % 8) == 0 and imp_off + imp_size <= file_size

    sections = []
    for i in 0 .. num_sec - 1:
        raw_off = read_u32be(stream, sec_off + i * 8 + 0)
        size    = read_u32be(stream, sec_off + i * 8 + 4)
        is_exec = (raw_off & 1) != 0
        f_off   = raw_off & 0xFFFFFFFE
        if f_off > 0:
            assert f_off + size <= file_size
        sections.append({ index: i, is_exec, file_offset: f_off, size })

    imports = []
    for i in 0 .. (imp_size / 8) - 1:
        mod_id = read_u32be(stream, imp_off + i * 8 + 0)
        r_off  = read_u32be(stream, imp_off + i * 8 + 4)
        assert r_off >= rel_off and r_off + 8 <= file_size
        imports.append({ module_id: mod_id, rel_offset: r_off })

    return { id, version, bss_size, align, bss_align, fix_size, sections, imports }

function apply_rel_import(stream, file_size, current_mod, imp, loaded_modules, ram):
    pos = imp.rel_offset
    P = 0
    active_sec = null

    while pos + 8 <= file_size:
        delta    = read_u16be(stream, pos + 0)
        rtype    = read_u8(stream,    pos + 2)
        sec_idx  = read_u8(stream,    pos + 3)
        addend   = read_u32be(stream, pos + 4)
        pos += 8

        if rtype == 203: // R_DOLPHIN_END
            break
        elif rtype == 202: // R_DOLPHIN_SECTION
            assert sec_idx < len(current_mod.sections)
            active_sec = current_mod.sections[sec_idx]
            assert active_sec.file_offset > 0
            P = active_sec.ram_base
            continue
        elif rtype == 201: // R_DOLPHIN_NOP
            P += delta
            continue
        elif rtype == 204: // R_DOLPHIN_MRKREF
            continue

        assert active_sec != null
        P += delta
        assert P >= active_sec.ram_base and P < active_sec.ram_base + active_sec.size

        if imp.module_id == 0:
            S = addend
        else:
            target_mod = loaded_modules.get(imp.module_id)
            if target_mod == null:
                continue // Deferred until target module is loaded
            assert sec_idx < len(target_mod.sections)
            S = target_mod.sections[sec_idx].ram_base + addend

        if rtype == 1:    ram.write_u32be(P, S)
        elif rtype == 2:  ram.write_u32be(P, (ram.read_u32be(P) & ~0x03FFFFFC) | (S & 0x03FFFFFC))
        elif rtype in {3, 4}: ram.write_u16be(P, S & 0xFFFF)
        elif rtype == 5:  ram.write_u16be(P, (S >> 16) & 0xFFFF)
        elif rtype == 6:  ram.write_u16be(P, ((S + 0x8000) >> 16) & 0xFFFF)
        elif rtype in {7, 8, 9}: ram.write_u32be(P, (ram.read_u32be(P) & ~0xFFFC) | (S & 0xFFFC))
        elif rtype == 10: ram.write_u32be(P, (ram.read_u32be(P) & ~0x03FFFFFC) | ((S - P) & 0x03FFFFFC))
        elif rtype in {11, 12, 13}: ram.write_u32be(P, (ram.read_u32be(P) & ~0xFFFC) | ((S - P) & 0xFFFC))

6. Provenance & Confidence

Module name tables & R_DOLPHIN_MRKREF: Retail .rel files frequently leave NameOffset/NameSize populated relative to an external .str file that is omitted from retail discs. Similarly, R_DOLPHIN_MRKREF (204) appears only in specific linker configurations and performs no patch in standard OSLink.

  • Confirmed SDK Spec: Header fields for v1 (0x40), v2 (0x48), and v3 (0x4C), OSSectionInfo bit-0 executable flag, OSImportInfo structure, and OSRel opcodes 0..13 and 201..203 match Dolphin OS runtime linking behavior across GameCube and Wii.
  • Revision-Dependent: Support for v2 alignment fields and v3 FixSize / OSLinkFixed depends on the Dolphin SDK version linked into the host .dol.
