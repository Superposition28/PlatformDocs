Nintendo DS Icon & Localized Title Banner

Platform Binary Specification · Firmware UI Metadata

The Nintendo DS Banner structure stores the 32×32 4bpp tiled application icon, 16-color BGR555 palette, and localized multi-line UTF-16LE game titles displayed by the system launcher. Later revisions expand language coverage (Chinese and Korean) and add DSi (TWL) 8-frame animated icon support.

1. Identification & Scope

The banner starts at the ROM offset recorded at header offset 0x0068 (banner_offset). If banner_offset == 0, the cartridge provides no icon or title block. A valid banner is identified by its u16le version field at 0x0000 and verified against one or more CRC-16/MODBUS checksums at 0x0002–0x0008.

  • 0x0001 (0x0840 / 2,112 bytes): Standard NDS banner with 6 titles (Japanese, English, French, German, Italian, Spanish).
  • 0x0002 (0x0940 / 2,368 bytes): Adds Chinese title slot and crc16_v2.
  • 0x0003 (0x0A40 / 2,624 bytes): Adds Korean title slot and crc16_v3.
  • 0x0103 (0x23C0 / 9,152 bytes): DSi animated banner adding 8 icon bitmaps, 8 palettes, a 64-step animation sequence, and crc16_dsi.

3. Flags, Enums & Decoding Formulas

4bpp Tiled Icon Pixel Decoding

Each 32×32 icon (512 bytes) is partitioned into a 4×4 grid of 8×8-pixel tiles stored in row-major tile order (ty = 0..3, tx = 0..3):

tile_index  = ty * 4 + tx
tile_offset = tile_index * 32
for py in 0..7:
    for px in 0..7:
        byte_val  = bitmap[tile_offset + py * 4 + (px >> 1)]
        color_idx = (byte_val & 0x0F) if (px & 1) == 0 else (byte_val >> 4)
        pixel_x   = tx * 8 + px
        pixel_y   = ty * 8 + py

BGR555 Palette Decoding

Color index 0 is always fully transparent (RGBA = (0, 0, 0, 0)) regardless of the value stored in palette[0]. Indices 1..15 decode from 15-bit BGR555:

c  = palette[color_idx]
r5 =  c        & 0x1F
g5 = (c >>  5) & 0x1F
b5 = (c >> 10) & 0x1F
r8 = (r5 << 3) | (r5 >> 2)
g8 = (g5 << 3) | (g5 >> 2)
b8 = (b5 << 3) | (b5 >> 2)
alpha = 255

DSi Animation Sequence Token (u16le at 0x2340)

  • Bits 0–7 (token & 0x00FF): Frame duration in 60 Hz display frames (0x00 terminates/loops the sequence).
  • Bits 8–10 ((token >> 8) & 0x07): Bitmap frame index (0..7 in dsi_icon_frames).
  • Bits 11–13 ((token >> 11) & 0x07): Palette index (0..7 in dsi_icon_palettes).
  • Bit 14 ((token >> 14) & 0x01): Horizontal flip flag.
  • Bit 15 ((token >> 15) & 0x01): Vertical flip flag.

4. Edge Cases & Loader/Parser Rules

  • Multi-Line Titles: Each 256-byte title slot holds up to 128 UTF-16LE code units, terminated by 0x0000 and padded with zeroes. Line breaks (typically 2 or 3 lines for title and publisher/subtitle) use LF (0x000A).
  • Incremental CRC Validation: A version = 0x0103 banner MUST satisfy all four CRCs (crc16_v1, crc16_v2, crc16_v3, and crc16_dsi) so backward-compatible NTR consoles can validate crc16_v1 and display the static icon at 0x0020.
  • Missing Language Fallback: Unused language slots are commonly filled identically to the primary English or Japanese title, or left zero-filled; parsers should fall back to English (title_en) or the first non-empty title slot.
  • ROM Alignment: Banners are typically padded or aligned at 0x200-byte boundaries in ROM, though banner_offset specifies the exact start byte.

5. Parser Pseudocode

function parse_nds_banner(rom_bytes, banner_offset):
    assert banner_offset != 0 and banner_offset + 0x0840 <= len(rom_bytes)
    b = rom_bytes[banner_offset :]
    version = read_u16le(b, 0x0000)

    required_size = {
        0x0001: 0x0840,
        0x0002: 0x0940,
        0x0003: 0x0A40,
        0x0103: 0x23C0,
    }[version]
    assert len(b) >= required_size

    # Verify version-appropriate CRCs (CRC-16/MODBUS)
    assert crc16_modbus(b[0x0020 : 0x0840]) == read_u16le(b, 0x0002)
    if version >= 0x0002:
        assert crc16_modbus(b[0x0020 : 0x0940]) == read_u16le(b, 0x0004)
    if version >= 0x0003:
        assert crc16_modbus(b[0x0020 : 0x0A40]) == read_u16le(b, 0x0006)
    if version == 0x0103:
        assert crc16_modbus(b[0x1240 : 0x23C0]) == read_u16le(b, 0x0008)

    function decode_icon(bitmap_512, pal_32):
        pal = [read_u16le(pal_32, i * 2) for i in range(16)]
        rgba = allocate_rgba(32, 32)
        for ty in range(4):
            for tx in range(4):
                tile_off = (ty * 4 + tx) * 32
                for py in range(8):
                    for px in range(8):
                        byte_val = bitmap_512[tile_off + py * 4 + (px >> 1)]
                        idx = (byte_val & 0x0F) if (px & 1) == 0 else (byte_val >> 4)
                        if idx == 0:
                            rgba[ty * 8 + py][tx * 8 + px] = (0, 0, 0, 0)
                        else:
                            c = pal[idx]
                            r = ((c & 0x1F) << 3) | ((c & 0x1F) >> 2)
                            g = (((c >> 5) & 0x1F) << 3) | (((c >> 5) & 0x1F) >> 2)
                            bl = (((c >> 10) & 0x1F) << 3) | (((c >> 10) & 0x1F) >> 2)
                            rgba[ty * 8 + py][tx * 8 + px] = (r, g, bl, 255)
        return rgba

    static_icon = decode_icon(b[0x0020 : 0x0220], b[0x0220 : 0x0240])

    lang_names = ["ja", "en", "fr", "de", "it", "es"]
    if version >= 0x0002: lang_names.append("zh")
    if version >= 0x0003: lang_names.append("ko")

    titles = {}
    for idx, lang in enumerate(lang_names):
        raw_str = b[0x0240 + idx * 256 : 0x0240 + (idx + 1) * 256]
        titles[lang] = decode_utf16le_until_null(raw_str)

    dsi_anim = null
    if version == 0x0103:
        frames   = [b[0x1240 + i * 512 : 0x1240 + (i + 1) * 512] for i in range(8)]
        palettes = [b[0x2240 + i * 32  : 0x2240 + (i + 1) * 32]  for i in range(8)]
        seq = []
        for i in range(64):
            tok = read_u16le(b, 0x2340 + i * 2)
            dur = tok & 0xFF
            if dur == 0:
                break
            seq.append({
                duration: dur,
                frame:    (tok >> 8) & 0x07,
                palette:  (tok >> 11) & 0x07,
                flip_x:   (tok & 0x4000) != 0,
                flip_y:   (tok & 0x8000) != 0,
            })
        dsi_anim = { frames: frames, palettes: palettes, sequence: seq }

    return { version: version, static_icon: static_icon, titles: titles, dsi_anim: dsi_anim }

6. Provenance & Confidence

Banner versions 0x0001, 0x0002, 0x0003, and 0x0103, including CRC-16 coverage ranges, 4bpp tile ordering, BGR555 encoding, and UTF-16LE title slots, are confirmed across NTR and TWL system firmware behavior.

Caveats: The 0x0A40–0x123F gap in 0x0103 banners is reserved for potential additional languages and is zero-filled on standard releases; it is not covered by crc16_v3 or crc16_dsi. Custom homebrew banners occasionally omit valid crc16_v2/crc16_v3 checksums or set banner_offset to 0.
