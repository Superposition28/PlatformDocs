ARM9 / ARM7 Overlay Tables (y9.bin / y7.bin) & BLZ Compression

Platform Binary Specification · Dynamic Code Overlays & Backwards LZ

Nintendo DS titles exceeding static Main RAM or WRAM budgets dynamically page code and read-only data segments using ARM9 (y9.bin) and ARM7 (y7.bin) overlay descriptor tables. Overlay payloads and compressed static arm9.bin suffixes are packed with Nitro SDK backwards LZ77 (BLZ) compression so they can decompress in-place.

1. Identification & Scope

The ROM header locates the ARM9 overlay table at 0x0050 (arm9_overlay_offset, arm9_overlay_size) and the ARM7 overlay table at 0x0058 (arm7_overlay_offset, arm7_overlay_size). Each table is an integer multiple of 32 bytes (entry_count = table_size / 32), with no header or magic signature.

When an overlay entry sets its compression flag, the FAT file referenced by file_id is compressed using Nitro SDK BLZ (Backwards LZ77), identified by an 8-byte (or padded 9–11-byte) footer positioned at the very end of the file buffer. All integers in both the overlay tables and BLZ footer are little-endian.

3. Flags, Enums & Decoding Formulas

Overlay Entry Bitfields (0x1C)

  • compressed_size = flags_and_size & 0x00FFFFFF
  • flags = (flags_and_size >> 24) & 0xFF:
    • Bit 0 (0x01): is_compressed — 1 if the FAT payload is BLZ-compressed, 0 if stored as raw uncompressed binary of length ram_size.
    • Bit 1 (0x02): is_authenticated — 1 when HMAC/authentication metadata is associated with the overlay (used in signed/TWL contexts).
    • Bits 2–7: Reserved (zero).

BLZ Footer & Bitstream Decoding

BLZ compresses and decompresses backwards from high addresses to low addresses. Given a buffer of length bottom:

  • buffer_top_offset = buffer_top_and_hdr & 0x00FFFFFF
  • header_len = (buffer_top_and_hdr >> 24) & 0xFF
  • Compressed input range: reads backwards from src = bottom - header_len down to stop_src = bottom - buffer_top_offset. Bytes in [0, stop_src) are an uncompressed prefix copied verbatim.
  • Output write pointer: starts at dst = bottom + inc_size and writes backwards down to stop_src. Total decompressed size is bottom + inc_size.
  • Token encoding: Each control byte flags read via *(--src) governs 8 tokens from MSB (bit 7) to LSB (bit 0):
    • Flag bit == 0: literal byte *(--dst) = *(--src).
    • Flag bit == 1: 2-byte backreference b1 = *(--src), b2 = *(--src):
      • match_len = (b1 >> 4) + 3 (range 3..18 bytes)
      • disp = (((b1 & 0x0F) << 8) | b2) + 3 (lookahead distance into already-decompressed higher addresses relative to the newly written destination byte dst - 1; equivalently *(old_dst + disp - 1) before decrementing dst)

4. Edge Cases & Loader/Parser Rules

  • In-Place Overlay Loading: The Nitro SDK loader reads the overlay file from FAT directly into ram_address, runs MIi_UncompressBackward in place if flags & 0x01 is set (expanding up to ram_address + ram_size), zeroes bss_size bytes at ram_address + ram_size, flushes the ARM9 data/instruction caches, and executes function pointers from static_init_start up to static_init_end.
  • arm9.bin Self-Decompressing Suffix: Static arm9.bin binaries may also be BLZ-compressed. Unlike overlays, the ROM header has no compression flag for arm9.bin; instead, Nitro SDK embeds a module-parameter block containing magic 0xDEC00621 (21 06 C0 DE on disk) with pointers to the compressed region end so the startup stub calls MIi_UncompressBackward before entering main code.
  • Padding & Size Discrepancy: Because FAT entries may be 4-byte aligned, check compressed_size at 0x1C when locating the BLZ bottom if the FAT file has trailing alignment bytes, or verify header_len lies in 8..11 and buffer_top_offset <= bottom.
  • Empty Overlay Tables: When arm9_overlay_size == 0 or arm7_overlay_size == 0, the corresponding offset in the ROM header is 0 and no overlay table exists.

5. Parser & Decompressor Pseudocode

function parse_overlay_table(table_bytes):
    assert len(table_bytes) % 32 == 0
    overlays = []
    for off in range(0, len(table_bytes), 32):
        flags_size = read_u32le(table_bytes, off + 0x1C)
        overlays.append({
            overlay_id:        read_u32le(table_bytes, off + 0x00),
            ram_address:       read_u32le(table_bytes, off + 0x04),
            ram_size:          read_u32le(table_bytes, off + 0x08),
            bss_size:          read_u32le(table_bytes, off + 0x0C),
            static_init_start: read_u32le(table_bytes, off + 0x10),
            static_init_end:   read_u32le(table_bytes, off + 0x14),
            file_id:           read_u32le(table_bytes, off + 0x18),
            compressed_size:   flags_size & 0x00FFFFFF,
            is_compressed:     (flags_size & 0x01000000) != 0,
            is_authenticated:  (flags_size & 0x02000000) != 0,
        })
    return overlays

function blz_decompress(comp_buf):
    bottom = len(comp_buf)
    assert bottom >= 8

    top_and_hdr = read_u32le(comp_buf, bottom - 8)
    inc_size    = read_u32le(comp_buf, bottom - 4)

    top_offset  = top_and_hdr & 0x00FFFFFF
    header_len  = (top_and_hdr >> 24) & 0xFF
    assert 8 <= header_len <= bottom
    assert header_len <= top_offset <= bottom

    stop_src = bottom - top_offset
    out_len  = bottom + inc_size
    out      = allocate_bytes(out_len)

    # Copy uncompressed prefix [0 .. stop_src)
    out[0 : stop_src] = comp_buf[0 : stop_src]

    src = bottom - header_len
    dst = out_len

    while src > stop_src:
        flags = comp_buf[src - 1]
        src -= 1
        for bit in range(8):
            if src <= stop_src:
                break
            if (flags & (0x80 >> bit)) == 0:
                src -= 1
                dst -= 1
                out[dst] = comp_buf[src]
            else:
                assert src >= stop_src + 2
                b1 = comp_buf[src - 1]
                b2 = comp_buf[src - 2]
                src -= 2
                match_len = (b1 >> 4) + 3
                disp      = (((b1 & 0x0F) << 8) | b2) + 3
                for _ in range(match_len):
                    dst -= 1
                    assert dst + disp < out_len
                    out[dst] = out[dst + disp]

    assert dst == stop_src
    return out

6. Provenance & Confidence

The 32-byte overlay table layout (y9.bin / y7.bin) and BLZ backwards-LZ decompression logic are confirmed across Nitro SDK overlay managers and standard NDS ROM toolchains.

Caveats: Overlay flag bit 1 (0x02000000) and higher bits depend on SDK revision and DSi authentication extensions; clean-room extraction tools only require bit 0 (0x01000000) to determine whether BLZ decompression applies. For static arm9.bin images, locate the 0xDEC00621 module parameter marker before attempting BLZ decompression, as uncompressed arm9.bin files have no BLZ footer.
