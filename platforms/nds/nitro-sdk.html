Nitro SDK Containers (NARC / CARC, SDAT) & BIOS LZ10 / LZ11

Platform Binary Specification · SDK Archives, Sound Data & Compression

The Nintendo Nitro SDK provides standard archive, audio, and BIOS decompression primitives inherited by DS titles: NARC/CARC resource archives (sharing NitroFS-style FAT/FNT blocks), SDAT sound data archives, and LZ10/LZ11 compression streams decoded via NDS BIOS SWI 0x11/0x12 or Nitro SDK MI_UncompressLZ*.

1. Identification & Scope

Nitro SDK binary containers share a 16-byte (or extended 64-byte in SDAT) standard header starting with a 4-byte ASCII signature, a 0xFFFE little-endian byte-order mark (bytes FE FF on disk), a version word (0x0100 for v1.0), total file size, header size, and block/chunk count:

  • NARC (4E 41 52 43): Uncompressed Nitro Archive containing three sequential blocks whose on-disk chunk IDs are stored in little-endian FourCC order: BTAF (FATB), BTNF (FNTB), and GMIF (FIMG).
  • CARC: Compressed NARC — a standard NARC payload wrapped in a BIOS LZ10 (0x10) or LZ11 (0x11) header (not a distinct container magic).
  • SDAT (53 44 41 54): Nitro Sound Data archive header (64 bytes) indexing SYMB, INFO, FAT , and FILE blocks (literal ASCII block IDs, not reversed).
  • BIOS LZ10 / LZ11: Prefixed by a 4-byte compression descriptor whose byte 0 is 0x10 (LZ10) or 0x11 (LZ11) and bytes 1..3 encode the 24-bit little-endian decompressed size.

3. Flags, Enums & Decoding Formulas

NARC Payload Offset Formula

Unlike NitroFS ROM FAT entries (which are absolute ROM offsets), NARC FATB entries are relative to the start of the FIMG (GMIF) data payload:

abs_start = fimg_chunk_offset + 8 + fatb_entry.start_offset
abs_end   = fimg_chunk_offset + 8 + fatb_entry.end_offset
file_data = narc_bytes[abs_start : abs_end]

LZ10 (0x10) Bitstream Decoding

Reads a flag byte (MSB-first, bit 7 down to bit 0). Bit 0 copies 1 literal byte; bit 1 reads 2 bytes (b0, b1):

  • length = (b0 >> 4) + 3 (3..18 bytes)
  • disp = (((b0 & 0x0F) << 8) | b1) + 1 (1..4096 bytes backwards in output)

LZ11 (0x11) Bitstream Decoding

Reads a flag byte (MSB-first). Bit 0 copies 1 literal byte; bit 1 inspects the high nibble n = (b0 >> 4) of the first token byte:

  • n == 0 (3-byte token b0, b1, b2): length = (((b0 & 0x0F) << 4) | (b1 >> 4)) + 0x11 (17..272), disp = (((b1 & 0x0F) << 8) | b2) + 1
  • n == 1 (4-byte token b0, b1, b2, b3): length = (((b0 & 0x0F) << 12) | (b1 << 4) | (b2 >> 4)) + 0x111 (273..65808), disp = (((b2 & 0x0F) << 8) | b3) + 1
  • n >= 2 (2-byte token b0, b1): length = n + 1 (3..16), disp = (((b0 & 0x0F) << 8) | b1) + 1

4. Edge Cases & Loader/Parser Rules

  • Nameless NARCs: Many .narc archives omit filenames to save space. In those files, the BTNF chunk is 16 bytes long (chunk_size == 0x10) with a single dummy root directory entry (subtable_offset = 4 or 8, first_file_id = 0, dir_count = 1) and no filename entries; parsers must fall back to numeric indexing (0..file_count-1) when BTNF contains no names.
  • CARC Detection: .carc files start with 0x10 or 0x11 rather than "NARC". Decompress the stream first using LZ10/LZ11, then verify the "NARC" signature at offset 0x00 of the output.
  • SDAT Stripped SYMB: When block_count == 3, symb_offset and symb_size are both 0; inner sound assets remain fully addressable by numeric index via INFO and FAT .
  • Overlapping LZ Backreferences: Both LZ10 and LZ11 allow disp < length (run-length repetition); decoders MUST copy byte-by-byte from out[dst - disp] rather than bulk-copying slices.

5. Parser Pseudocode

function decompress_lz10_lz11(src):
    comp_type = src[0]
    assert comp_type in (0x10, 0x11)
    decomp_size = src[1] | (src[2] << 8) | (src[3] << 16)
    pos = 4
    if comp_type == 0x11 and decomp_size == 0:
        decomp_size = read_u32le(src, 4)
        pos = 8

    out = allocate_bytes(decomp_size)
    dst = 0
    while dst < decomp_size:
        flags = src[pos]; pos += 1
        for bit in range(8):
            if dst >= decomp_size:
                break
            if (flags & (0x80 >> bit)) == 0:
                out[dst] = src[pos]
                dst += 1; pos += 1
            else:
                b0 = src[pos]; pos += 1
                if comp_type == 0x10:
                    b1 = src[pos]; pos += 1
                    length = (b0 >> 4) + 3
                    disp   = (((b0 & 0x0F) << 8) | b1) + 1
                else:
                    n = b0 >> 4
                    if n == 0:
                        b1 = src[pos]; b2 = src[pos + 1]; pos += 2
                        length = (((b0 & 0x0F) << 4) | (b1 >> 4)) + 0x11
                        disp   = (((b1 & 0x0F) << 8) | b2) + 1
                    elif n == 1:
                        b1 = src[pos]; b2 = src[pos + 1]; b3 = src[pos + 2]; pos += 3
                        length = (((b0 & 0x0F) << 12) | (b1 << 4) | (b2 >> 4)) + 0x111
                        disp   = (((b2 & 0x0F) << 8) | b3) + 1
                    else:
                        b1 = src[pos]; pos += 1
                        length = n + 1
                        disp   = (((b0 & 0x0F) << 8) | b1) + 1
                for _ in range(length):
                    assert dst - disp >= 0 and dst < decomp_size
                    out[dst] = out[dst - disp]
                    dst += 1
    return out

function parse_narc(buf):
    if buf[0] in (0x10, 0x11):
        buf = decompress_lz10_lz11(buf)

    assert ascii(buf[0x00:0x04]) == "NARC"
    assert read_u16le(buf, 0x04) == 0xFFFE
    hdr_size = read_u16le(buf, 0x0C)
    assert hdr_size == 0x0010

    fatb_off  = hdr_size
    assert ascii(buf[fatb_off : fatb_off + 4]) == "BTAF"
    fatb_size = read_u32le(buf, fatb_off + 4)
    n_files   = read_u16le(buf, fatb_off + 8)

    fntb_off  = fatb_off + fatb_size
    assert ascii(buf[fntb_off : fntb_off + 4]) == "BTNF"
    fntb_size = read_u32le(buf, fntb_off + 4)

    fimg_off  = fntb_off + fntb_size
    assert ascii(buf[fimg_off : fimg_off + 4]) == "GMIF"
    data_base = fimg_off + 8

    entries = []
    for i in range(n_files):
        s = read_u32le(buf, fatb_off + 12 + i * 8)
        e = read_u32le(buf, fatb_off + 16 + i * 8)
        entries.append(buf[data_base + s : data_base + e])
    return entries

function parse_sdat_header(buf):
    assert ascii(buf[0x00:0x04]) == "SDAT"
    assert read_u16le(buf, 0x04) == 0xFFFE
    fat_off = read_u32le(buf, 0x20)
    assert ascii(buf[fat_off : fat_off + 4]) == "FAT "
    count = read_u32le(buf, fat_off + 8)
    assets = []
    for i in range(count):
        rec = fat_off + 12 + i * 16
        f_off  = read_u32le(buf, rec + 0)
        f_size = read_u32le(buf, rec + 4)
        assets.append(buf[f_off : f_off + f_size])
    return assets

6. Provenance & Confidence

The NARC header and chunk structures (BTAF/BTNF/GMIF), SDAT 64-byte header and FAT table, and BIOS LZ10/LZ11 compression encodings are confirmed across Nitro SDK container formats and ARM BIOS decompression behavior.

Caveats: NARC chunk signatures appear reversed on disk (BTAF, BTNF, GMIF) because Nitro SDK writes little-endian 32-bit FourCC constants, whereas SDAT writes literal forward ASCII block IDs (SYMB, INFO, FAT , FILE). Inner SDAT sub-formats (SSEQ, SSAR, SBNK, SWAR, STRM) and Nitro G2D/G3D graphics containers (NCGR, NCLR, NSBMD, etc.) follow the same 16-byte Nitro header convention but are outside the scope of this container header specification.
