UMD ISO-9660 Directory Layout, UMD_DATA.BIN & Standard Compressed Image Containers (CSO/CISO & DAX)

PSP Optical Disc & Preservation Containers · Little-Endian

Retail PSP UMD discs use a standard 2048-byte-sector ISO-9660 filesystem (disc0:/) containing /UMD_DATA.BIN and the /PSP_GAME/ tree (metadata, XMB assets, SYSDIR/EBOOT.BIN, optional UPDATE/). For archival and virtual-disc mounting, two standard sector-compressed container formats wrap the raw ISO-9660 stream: CSO (CISO) and DAX.

1. Identification & Scope

A raw UMD dump is a 2048-byte-per-sector ISO-9660 image identified by the Primary Volume Descriptor (PVD) signature 01 43 44 30 30 31 (\x01CD001) at sector 16 (byte offset 0x8000). Single-layer UMDs cap around 900 MB and dual-layer UMDs around 1.8 GB.

Compressed UMD containers store random-access compressed chunks of that raw ISO stream: CSO/CISO begins with 43 49 53 4F ("CISO") and compresses 2048-byte blocks (default), while DAX begins with 44 41 58 00 ("DAX\x00") and compresses 8192-byte (0x2000) frames.

CISO / CSO Header Layout (24 / 0x18 bytes)
Offset Size Type Field Description
0x00 4 u8[4] magic Constant signature 43 49 53 4F ("CISO")
0x04 4 u32le header_size Header byte size (0x00000018 = 24; early encoders sometimes wrote 0)
0x08 8 u64le total_bytes Total uncompressed ISO size in bytes
0x10 4 u32le block_size Uncompressed sector/block size in bytes (typically 0x0800 = 2048)
0x14 1 u8 version Format version (1 for CISO v1; 2 for CISO v2)
0x15 1 u8 align Bit-shift alignment factor applied to block index offsets (offset = (idx & 0x7FFFFFFF) << align)
0x16 2 u8[2] reserved Reserved padding bytes (00 00)
0x18 (N+1)*4 u32le[N+1] block_index Block offset table where N = ceil(total_bytes / block_size); final block_index[N] marks end of last block
DAX Header Layout (32 / 0x20 bytes)
Offset Size Type Field Description
0x00 4 u8[4] magic Constant signature 44 41 58 00 ("DAX\x00")
0x04 4 u32le orig_size Total uncompressed ISO size in bytes
0x08 4 u32le version Format version (0 = standard; 1 = supports NC uncompressed frame ranges)
0x0C 4 u32le nc_areas Count of 8-byte non-compressed (NC) frame range records
0x10 16 u32le[4] reserved Reserved zero-filled header words
0x20 M * 4 u32le[M] frame_offsets Absolute offsets of M = ceil(orig_size / 0x2000) frames
0x20 + M*4 M * 2 u16le[M] frame_sizes Compressed byte size of each 8192-byte frame
0x20 + M*6 nc_areas*8 {u32le,u32le}[] nc_area_table Optional array of (start_frame, end_frame) pairs stored uncompressed (8192 bytes raw)

3. Flags, Block Index & Decoding Formulas

CISO & DAX Block Decoding Formulas
Container Field / Bit Type Formula Meaning
CISO block_index[i] MSB (bit 31) u32le flag = (entry & 0x80000000) != 0 In CISO v1: 1 = stored uncompressed (raw block_size bytes); 0 = raw RFC 1951 deflate stream (no zlib header)
CISO block_index[i] bits 0..30 u64 start = (u64(entry & 0x7FFFFFFF)) << align Byte offset of block i in the .cso file
CISO Stored block length u64 stored_size = ((u64(next & 0x7FFFFFFF)) << align) - start Byte span of compressed or raw block data before stripping alignment padding
CISO v2 Bit 31 + size check u32le if flag and stored_size < block_size: LZ4 else raw In CISO v2 (version == 2), bit 31 selects LZ4 compression when stored_size < block_size, or raw uncompressed when equal
DAX Fixed frame size u32 DAX_FRAME_SIZE = 0x2000 (8192 bytes) 4 ISO-9660 sectors per DAX frame; compressed frames use standard zlib stream (wbits = +15)
UMD_DATA.BIN Pipe-delimited text char[] <DISC_ID>|<HEX16>|<FLAGS>|<TYPE> Example format: UCUS-98600|0000000000000000|0001|G (G = Game, V = Video, A = Audio)

4. Edge Cases & Loader Rules

  • CISO header_size == 0 quirk: Early CSO compressors wrote 0 into offset 0x04 instead of 24 (0x18). Parsers should normalize header_size == 0 to 0x18 and begin reading block_index at 0x18.
  • 64-bit shift requirement in CISO: Even though each block_index entry is 32 bits, shifting (entry & 0x7FFFFFFF) << align can exceed 0xFFFFFFFF when align > 0. Always cast the masked value to 64-bit unsigned integer before shifting.
  • Raw deflate (CSO) vs. zlib wrapper (DAX): CISO v1 omits the 2-byte zlib header and 4-byte Adler-32 trailer (inflate with wbits = -15), whereas DAX uses standard zlib-wrapped deflate streams (wbits = +15).
  • BOOT.BIN vs. EBOOT.BIN on retail UMDs: Retail UMDs execute /PSP_GAME/SYSDIR/EBOOT.BIN (~PSP). BOOT.BIN is often zero-filled or cleared in retail disc mastering while retaining a valid ISO-9660 directory entry; parsers must not assume BOOT.BIN contains a valid ELF on retail discs.
  • ISO-9660 version suffix: Standard ISO-9660 directory entries may carry the ;1 file version identifier (e.g., EBOOT.BIN;1); virtual disc0:/ drivers strip ;1 during lookup.

5. Step-by-Step Parser Pseudocode

function open_ciso(stream):
    seek(stream, 0x00)
    if read_bytes(stream, 4) != b"CISO":
        error("Invalid CISO magic")

    header_size = read_u32le(stream)
    if header_size == 0:
        header_size = 0x18
    total_bytes = read_u64le(stream)
    block_size  = read_u32le(stream)
    version     = read_u8(stream)
    align       = read_u8(stream)
    _reserved   = read_bytes(stream, 2)

    if block_size == 0:
        error("Invalid CISO block_size = 0")

    num_blocks = (total_bytes + block_size - 1) // block_size
    seek(stream, header_size)
    indices = [read_u32le(stream) for _ in range(num_blocks + 1)]
    return {
        "total_bytes": total_bytes, "block_size": block_size,
        "version": version, "align": align, "indices": indices
    }

function read_ciso_block(stream, ciso, block_idx):
    raw_entry  = ciso["indices"][block_idx]
    next_entry = ciso["indices"][block_idx + 1]
    flag       = (raw_entry & 0x80000000) != 0
    start      = (uint64(raw_entry  & 0x7FFFFFFF)) << ciso["align"]
    end        = (uint64(next_entry & 0x7FFFFFFF)) << ciso["align"]
    if end < start:
        error("Invalid CISO block offset order")

    seek(stream, start)
    chunk = read_bytes(stream, end - start)

    if ciso["version"] <= 1:
        if flag:
            return chunk[:ciso["block_size"]]
        return inflate_raw_deflate(chunk, expected_size=ciso["block_size"])
    elif ciso["version"] == 2:
        if not flag:
            return inflate_raw_deflate(chunk, expected_size=ciso["block_size"])
        elif len(chunk) >= ciso["block_size"]:
            return chunk[:ciso["block_size"]]
        else:
            return decompress_lz4_block(chunk, expected_size=ciso["block_size"])
    else:
        error("Unsupported CISO version")

function open_dax(stream):
    seek(stream, 0x00)
    if read_bytes(stream, 4) != b"DAX\x00":
        error("Invalid DAX magic")
    orig_size = read_u32le(stream)
    version   = read_u32le(stream)
    nc_areas  = read_u32le(stream)
    _reserved = read_bytes(stream, 16)

    num_frames    = (orig_size + 0x1FFF) // 0x2000
    frame_offsets = [read_u32le(stream) for _ in range(num_frames)]
    frame_sizes   = [read_u16le(stream) for _ in range(num_frames)]
    nc_ranges     = [(read_u32le(stream), read_u32le(stream)) for _ in range(nc_areas)]
    return {
        "orig_size": orig_size, "version": version,
        "frame_offsets": frame_offsets, "frame_sizes": frame_sizes, "nc_ranges": nc_ranges
    }

function read_dax_frame(stream, dax, frame_idx):
    offset = dax["frame_offsets"][frame_idx]
    size   = dax["frame_sizes"][frame_idx]
    seek(stream, offset)
    raw = read_bytes(stream, size)

    for (start_f, end_f) in dax["nc_ranges"]:
        if start_f <= frame_idx <= end_f:
            return raw

    return inflate_zlib(raw, expected_size=0x2000)

6. Provenance & Confidence

The ISO-9660 PVD specification, UMD directory hierarchy (/UMD_DATA.BIN, /PSP_GAME/SYSDIR/EBOOT.BIN), CISO v1 header/block index encoding, and DAX 0x2000-frame zlib format are confirmed across retail UMD media and standard preservation/loader implementations.

Container & disc-type caveats: CISO and DAX are community/emulator compressed preservation containers rather than official Sony disc formats. Some later CSO tools emit CISO v2 (LZ4 support via bit 31 when stored_size < block_size) or non-standard block_size values; verify version and block_size before assuming v1 raw deflate. Non-game UMD Video/Audio discs use UMD_VIDEO/ or UMD_AUDIO/ trees instead of PSP_GAME/.
