Original Xbox

Platform Architecture & Inherited Format Overview

Hardware, OS kernel, optical disc filesystem, executable, and resource/metadata specifications inherited from the Original Xbox (2001) hardware and Microsoft Xbox Development Kit (XDK) runtime.

CPU Architecture
Intel Pentium III (Coppermine-derived, x86 32-bit IA-32, 733 MHz, MMX/SSE)
System Memory
64 MB Unified Memory Architecture (UMA) DDR SDRAM shared between CPU and NV2A GPU (128 MB on XDK debug kits)
Byte Order
Little-endian across CPU, kernel structures, executables, optical filesystem, and D3D8 packed resources
OS / Kernel Model
Custom single-address-space microkernel (xboxkrnl.exe, Windows NT-derived) with ordinal thunk linking, no virtual swap, and statically linked XDK libraries
Primary Media
Proprietary dual-layer DVD-ROM (XGD1 with XDVDFS game partition), internal FATX hard disk (partitions for dashboard, cache, TDATA, and UDATA), and 8 MB Memory Units

Hardware & Kernel Execution Model

Unlike a general-purpose Windows PC, the Original Xbox executes one title at a time directly in a flat 32-bit physical-backed address space without user/kernel virtual isolation or dynamic DLL loading. All Win32/Xbox APIs (xapilib, d3d8, dsound, xnet) are statically compiled into the title executable (default.xbe), while hardware and filesystem services are imported exclusively by ordinal from the resident kernel (xboxkrnl.exe).

  • Boot & Verification: The boot ROM initializes hardware, verifies the RSA-2048 signature of default.xbe (or a dashboard/recovery XBE), maps its sections directly at BaseAddress (typically 0x00010000), unmasks the XOR-obfuscated entry point and kernel thunk table, resolves kernel ordinals, displays the embedded 100×17 startup logo, and transfers control to the title.
  • Optical Media Layout: Retail discs (XGD1) place a standard DVD-Video warning partition at sector 0 followed by the encrypted/authenticated XDVDFS game partition starting at byte offset 0x18300000. Trimmed XISO images start directly at the XDVDFS partition base (offset 0x00000000).
  • Persistent Storage & Title Metadata: Title data (TDATA\<TitleID>\) and user saves (UDATA\<TitleID>\) live on FATX volumes and use standardized UTF-16LE .xbx text descriptors alongside D3D8 XPR0 icon containers.

Scope Boundary

This section documents strictly platform-inherited Microsoft Xbox hardware, kernel, optical disc, and XDK formats. Title-specific archives, scripting runtimes, and middleware formats stored inside the XDVDFS tree are excluded.
