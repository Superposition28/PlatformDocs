1. Identification & Scope

param.sfo uses Sony's PSF (PlayStation Format) v1.1 binary table, recognized by the 4-byte signature 00 50 53 46 (\x00PSF) at offset 0x00 and version 0x00000101 at offset 0x04.

  • Endianness Context: All header offsets, index table fields, and integer parameter values inside param.sfo are little-endian. When param.sfo is extracted from a big-endian PS4 CNT .pkg (entry ID 0x1000), its internal bytes remain strictly little-endian.
  • Orbis Extensions: While the 20-byte header and 16-byte index records match PSP/PS3 PSF v1.1, PS4 introduces Orbis-specific keys (CONTENT_ID, APP_TYPE, ATTRIBUTE2, PUBTOOLINFO, FORMAT="obs", DOWNLOAD_DATA_SIZE, SAVEDATA_MAX_SIZE) and new bit definitions in ATTRIBUTE / ATTRIBUTE2.

2. Binary Layout Tables

PSF Header (20 bytes / 0x14 at offset 0x00)
Offset Size Type Field Description
0x00 4 u8[4] Magic Constant bytes 00 50 53 46 (\x00PSF).
0x04 4 u32le Version PSF format version: 0x00000101 (v1.1).
0x08 4 u32le KeyTableOffset Absolute byte offset to the packed ASCII key string table (normally 0x14 + EntryCount * 0x10).
0x0C 4 u32le DataTableOffset Absolute byte offset to the value data table (padded to 4-byte alignment after the Key Table).
0x10 4 u32le EntryCount Number of 16-byte index entries immediately following at 0x14.
PSF Index Entry Record (16 bytes / 0x10 each, EntryCount entries at 0x14)
Offset Size Type Field Description
0x00 2 u16le KeyOffset Offset relative to KeyTableOffset to a NUL-terminated ASCII key name.
0x02 2 u16le DataFormat Value type encoding (0x0004, 0x0204, or 0x0404).
0x04 4 u32le DataLen Actual used length of the value in bytes (including NUL byte for 0x0204; 4 for 0x0404).
0x08 4 u32le DataMaxLen Total reserved slot size in bytes inside the Data Table (4-byte aligned).
0x0C 4 u32le DataOffset Offset relative to DataTableOffset to the value payload.
Canonical Orbis param.sfo Keys
Key Format MaxLen Field Type Description
APP_TYPE 0x0404 4 u32le Application type (0 Not specified, 1 Paid Full App, 2 Upgradeable, 3 Demo, 4 Freemium).
APP_VER 0x0204 8 UTF-8 Application version string formatted as "MM.mm" (e.g., "01.00").
ATTRIBUTE 0x0404 4 u32le Primary 32-bit Orbis application capability & UI warning bitmask.
ATTRIBUTE2 0x0404 4 u32le Extended 32-bit Orbis capability bitmask (Share/broadcast, HDR, additional hardware flags).
CATEGORY 0x0204 4 UTF-8 2-to-3-character package/app category ("gd" Game Digital/Disc, "gp" Patch, "ac" DLC, "al" License, "sd" Save Data).
CONTENT_ID 0x0204 48 UTF-8 36-character PSN content identifier (e.g., XXYYYY-CUSA00000_00-0000000000000000).
DOWNLOAD_DATA_SIZE 0x0404 4 u32le Download/runtime persistent storage allocation quota (in MiB).
FORMAT 0x0204 4 UTF-8 Target platform identifier string: "obs" on PS4 Orbis.
PARENTAL_LEVEL 0x0404 4 u32le System parental control level (1 through 11).
PUBTOOLINFO 0x0204 512 UTF-8 Comma-separated build provenance string from Publishing Tools (e.g., c_date=YYYYMMDD,sdk_ver=0xxxxxxx).
SYSTEM_VER 0x0404 4 u32le Minimum required Orbis OS version encoded in packed BCD/hex (e.g., 0x04500001 = FW 4.50).
TITLE / TITLE_00..TITLE_29 0x0204 128 UTF-8 Default and localized shell display titles (by system language index).
TITLE_ID 0x0204 12 UTF-8 9-character product code (e.g., CUSA00000 / CUSAxxxxx).
VERSION 0x0204 8 UTF-8 Master package/disc version string (e.g., "01.00").

3. Flags, Enums & Decoding Formulas

PSF DataFormat Enumeration (u16le)
Value Type Encoding Rules
0x0004 UTF-8 Special / Binary Raw UTF-8 or opaque byte sequence; not guaranteed to be NUL-terminated within DataLen.
0x0204 UTF-8 String NUL-terminated UTF-8 string; DataLen includes the trailing 0x00 terminator and remaining bytes up to DataMaxLen are zero-padded.
0x0404 32-bit Integer 4-byte little-endian unsigned integer (u32le); DataLen == 4 and DataMaxLen == 4.
Orbis ATTRIBUTE Bitmask (u32le) — Confirmed Public SDK Flags
Bit / Mask Flag Meaning Notes
Bit 0 (0x00000001) Support Initial User Logout Controls behavior when the initial launching user logs out.
Bit 1 (0x00000002) Enter Button Assignment Selects system-default vs. Cross/Circle enter button convention.
Bit 2 (0x00000004) PS Move Warning Dialog Displays PlayStation Move safety dialog at startup when set.
Bit 3 (0x00000008) Stereoscopic 3D Warning Displays 3D display warning dialog at startup when set.
Bit 4 (0x00000010) Disable Auto-Suspend / Rest Mode Controls whether the system may suspend the application in Rest Mode.
Bit 14 (0x00004000) PS VR Required Indicates PlayStation VR headset is required to launch.
Bit 15 (0x00008000) PS VR Supported Indicates optional PlayStation VR headset support.
Bit 23 (0x00800000) Neo Mode (PS4 Pro) Enables PS4 Pro high-clock/Polaris Neo hardware mode when present.
Orbis ATTRIBUTE2 Bitmask (u32le) — Extended Capabilities
Bit / Mask Flag Meaning Notes
Bit 0 (0x00000001) Initial / Video Recording Control Controls Share video recording / capture policy flags (SDK-revision-dependent).
Bit 1 (0x00000002) Broadcast / Share Capability Extended Share broadcast behavior flag.
Bit 4 (0x00000010) HDR10 Support Advertises HDR output capability on supported displays (added in later Orbis SDKs).

SYSTEM_VER Decoding Formula: The 32-bit SYSTEM_VER field encodes the minimum Orbis OS version in hexadecimal/BCD nibbles:

major = (SYSTEM_VER >> 24) & 0xFF
minor = (SYSTEM_VER >> 16) & 0xFF   // BCD or hex, e.g., 0x50 -> .50
patch = SYSTEM_VER & 0xFFFF
// Example: 0x04500001 -> Orbis OS 4.50 (revision 0001)

4. Edge Cases & Loader/Parser Rules

  • Lexicographical Key Sorting: Orbis OS and orbis-pub-cmd require the Index Table entries to be sorted in strict ascending ASCII order by key name (e.g., APP_TYPE before APP_VER before ATTRIBUTE before ATTRIBUTE2). Unsorted entries can cause binary search lookups in the system shell to fail.
  • 4-Byte Alignment & Padding: DataTableOffset must be aligned to a 4-byte boundary. Individual DataMaxLen slots are padded to multiples of 4 bytes, and unused trailing bytes inside both the Key Table padding and Data Table slots should be zero-filled.
  • String Length Invariants: For DataFormat == 0x0204, validate 1 <= DataLen <= DataMaxLen and strip trailing 0x00 bytes rather than assuming a single NUL sits at DataLen - 1. For DataFormat == 0x0404, validate DataLen == 4 and DataMaxLen == 4.
  • Unknown or Undocumented Keys: Tools modifying param.sfo (for example updating APP_VER or ATTRIBUTE) must preserve unknown keys verbatim and recompute KeyTableOffset, DataTableOffset, and relative offsets rather than dropping unrecognized entries.

5. Step-by-Step Pseudocode

function ParseOrbisParamSfo(buf):
    if len(buf) < 0x14:
        error("Truncated PSF header")
    if buf[0x00 : 0x04] != b"\x00PSF":
        error("Invalid PSF magic")

    version          = read_u32le(buf, 0x04)
    key_table_offset = read_u32le(buf, 0x08)
    data_table_offset = read_u32le(buf, 0x0C)
    entry_count      = read_u32le(buf, 0x10)

    index_end = 0x14 + entry_count * 0x10
    if index_end > key_table_offset or key_table_offset > data_table_offset or data_table_offset > len(buf):
        error("Invalid PSF table offsets")

    entries = {}
    for i in 0 .. entry_count - 1:
        e_off       = 0x14 + i * 0x10
        key_rel     = read_u16le(buf, e_off + 0x00)
        data_fmt    = read_u16le(buf, e_off + 0x02)
        data_len    = read_u32le(buf, e_off + 0x04)
        data_maxlen = read_u32le(buf, e_off + 0x08)
        data_rel    = read_u32le(buf, e_off + 0x0C)

        key_start = key_table_offset + key_rel
        if key_start >= data_table_offset:
            error("Key offset out of Key Table bounds")
        key_name = read_cstr_ascii(buf, key_start, limit=data_table_offset)

        val_start = data_table_offset + data_rel
        if data_len > data_maxlen or val_start + data_maxlen > len(buf):
            error("Value bounds exceed file size for key: " + key_name)

        raw_val = buf[val_start : val_start + data_len]
        if data_fmt == 0x0404:
            if data_len != 4:
                error("Invalid u32le DataLen")
            entries[key_name] = read_u32le(raw_val, 0)
        elif data_fmt == 0x0204:
            entries[key_name] = decode_utf8(raw_val.rstrip(b"\x00"))
        elif data_fmt == 0x0004:
            entries[key_name] = raw_val
        else:
            error("Unknown PSF DataFormat: " + hex(data_fmt))

    return { version: version, params: entries }

6. Provenance & Confidence

Confirmed: PSF v1.1 Binary Format Revision-Dependent: ATTRIBUTE / ATTRIBUTE2 Bits Unverified: Reserved / Late-SDK Bits
  • Confirmed Specification: The 20-byte PSF v1.1 header, 16-byte index record layout, DataFormat codes (0x0004, 0x0204, 0x0404), 4-byte alignment, and ASCII sorting requirement are verified across PSP, PS3, and PS4 tools.
  • SDK-Revision-Dependent: Individual bits in ATTRIBUTE (such as PSVR and Neo/Pro flags) and ATTRIBUTE2 (such as HDR10) were introduced incrementally across Orbis OS firmware releases; bit assignments not explicitly listed above should be treated as SDK-revision-dependent or reserved.

Attribute Bitmask Caveat: Do not assume every bit in ATTRIBUTE or ATTRIBUTE2 is identical across all Orbis SDK versions. Preserve unknown bit flags unchanged when authoring or patching param.sfo.
