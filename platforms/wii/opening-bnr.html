Wii opening.bnr (IMET + U8 Archive Container)

System Menu Banner Package · Route #wii-opening-bnr

Nintendo Wii's System Menu channel and disc banner container combining a localized, MD5-verified IMET metadata header with a U8 (0x55AA382D) archive holding meta/icon.bin, meta/banner.bin, and meta/sound.bin.

1. Identification & Scope

The Wii System Menu displays animated banners and plays background audio for both inserted optical discs (via opening.bnr in the disc partition's root directory) and installed NAND channels (via Content 0, typically 00000000.app). Unlike the GameCube's fixed BNR1/BNR2 bitmap banner, Wii opening.bnr wraps a localized IMET header around a hierarchical U8 archive.

  • Magic Bytes & Alignment: On disc opening.bnr, a 64-byte zero block precedes the ASCII magic "IMET" (0x494D4554) at 0x0040, and the U8 archive (magic 0x55AA382D) begins at 0x0600. On NAND channel 00000000.app, 128 bytes of zero padding precede "IMET" at 0x0080, shifting the U8 archive start to 0x0640.
  • Endianness: Every numeric field in IMET, U8, IMD5, and child banner assets is big-endian; localized title strings use UTF-16BE.

2. Binary Layout Tables

Table 2.1 — IMET Metadata Header (0x600 Bytes; Relative to IMET Block Base B ∈ {0x00, 0x40})
Offset Size Type Field Description
B + 0x000 64 u8[64] ZeroPrefix 64 zero bytes included inside the 0x600-byte MD5-hashed IMET block (NAND apps have 0x40 extra leading zeros before B).
B + 0x040 4 char[4] Magic "IMET" (0x494D4554).
B + 0x044 4 u32be HashLength Size of the hashed IMET block (always 0x00000600 = 1,536 bytes).
B + 0x048 4 u32be Version Header version/unknown field (always 0x00000003 on retail Wii).
B + 0x04C 4 u32be IconSize Declared byte size of meta/icon.bin inside the U8 archive.
B + 0x050 4 u32be BannerSize Declared byte size of meta/banner.bin inside the U8 archive.
B + 0x054 4 u32be SoundSize Declared byte size of meta/sound.bin inside the U8 archive.
B + 0x058 4 u32be Flags Banner behavior flags (typically 0x00000000).
B + 0x05C 840 utf16be[10][42] ChannelNames 10 localized channel titles, 84 bytes (42 UTF-16BE code units) each (JP, EN, DE, FR, ES, IT, NL, ZH-S, ZH-T, KO).
B + 0x3A4 588 u8[588] ReservedPad Zero-filled padding up to B + 0x5F0.
B + 0x5F0 16 u8[16] Md5Hash MD5 digest over [B + 0x000 .. B + 0x5FF] with bytes [B + 0x5F0 .. B + 0x5FF] treated as zero.
Table 2.2 — U8 Archive Header & Node Entries (Starts at B + 0x600)
Offset Size Type Field Description
U8 + 0x00 4 u32be Tag U8 magic 0x55AA382D.
U8 + 0x04 4 u32be RootNodeOffset Offset from U8 start to node 0 (typically 0x00000020).
U8 + 0x08 4 u32be HeaderSize Combined byte size of the Node Table and String Table.
U8 + 0x0C 4 u32be DataOffset Offset from U8 start to aligned file payloads (typically align32(RootNodeOffset + HeaderSize)).
U8 + 0x10 16 u8[16] HeaderPad Zero padding (0x00).
Node + 0x00 1 u8 NodeType 0x00 = regular file; 0x01 = directory.
Node + 0x01 3 u24be NameOffset 24-bit big-endian byte offset into the String Table (U8 + RootNodeOffset + TotalNodes * 12).
Node + 0x04 4 u32be DataOrParent File: offset from U8 start to file bytes. Directory: parent node index (0 for root).
Node + 0x08 4 u32be SizeOrEndNode File: byte size. Directory: exclusive end node index (root.SizeOrEndNode == TotalNodes).
Table 2.3 — IMD5 Wrapper Header for meta/icon.bin, meta/banner.bin, & meta/sound.bin
Offset Size Type Field Description
0x00 4 char[4] Magic "IMD5" (0x494D4435).
0x04 4 u32be PayloadSize Byte size of the payload following the 32-byte IMD5 header.
0x08 8 u8[8] Padding Zero padding (0x00).
0x10 16 u8[16] PayloadMd5 MD5 digest of Payload[0 .. PayloadSize].
0x20 PayloadSize u8[] Payload Inner container: raw U8 (0x55AA382D), LZ77-compressed U8 (0x4C5A3737), or BNS /RIFF audio for sound.bin.

3. Flags, Enums & Decoding Formulas

3.1 IMET MD5 Verification Formula

  1. Locate the "IMET" signature at 0x0040 (base B = 0x0000) or 0x0080 (base B = 0x0040).
  2. Copy the 0x600 bytes spanning [B .. B + 0x5FF] into a mutable buffer.
  3. Save the 16-byte stored hash at buffer offset [0x5F0 .. 0x5FF], then overwrite [0x5F0 .. 0x5FF] with 16 zero bytes (0x00).
  4. Verify MD5(buffer[0x000 .. 0x5FF]) == stored_hash.

3.2 U8 Node Recursion Rules

The U8 node array stores a pre-order depth-first traversal of the filesystem starting at root node 0:

  • Read totalNodes = node[0].SizeOrEndNode. The string table starts at U8 + RootNodeOffset + totalNodes * 12.
  • A directory at index idx owns child indices idx + 1 .. node[idx].SizeOrEndNode - 1.
  • Maintain a stack of active directory bounds (dirPath, endNodeIndex). Before processing node i, pop any directory whose endNodeIndex == i. Read null-terminated name = cstr(stringTable + node[i].NameOffset); if directory, push (currentPath + "/" + name, node[i].SizeOrEndNode); if file, emit (currentPath + "/" + name, U8 + node[i].DataOrParent, node[i].SizeOrEndNode).

3.3 Expected Child Asset Hierarchy

  • /meta/icon.bin — IMD5 → (optional LZ77) → U8 containing arc/blyt/icon.brlyt, arc/anim/icon.brlan, and arc/timg/*.tpl (channel grid thumbnail).
  • /meta/banner.bin — IMD5 → (optional LZ77) → U8 containing arc/blyt/banner.brlyt, arc/anim/banner*.brlan, and arc/timg/*.tpl (full-screen channel preview).
  • /meta/sound.bin — IMD5 → (optional LZ77) → BNS (0x424E5320, Nintendo Wii DSP-ADPCM banner audio) or PCM RIFF WAV.

4. Edge Cases & Loader/Parser Rules

  • Disc vs. NAND Channel Offset Shift: Disc opening.bnr places "IMET" at 0x0040 (B = 0x0000), whereas NAND channel 00000000.app places "IMET" at 0x0080 (B = 0x0040). Parsers should probe both 0x0040 and 0x0080 instead of assuming a single fixed offset.
  • LZ77-Wrapped IMD5 Payloads: When the IMD5 payload inside icon.bin, banner.bin, or sound.bin starts with ASCII "LZ77" (0x4C5A3737) followed immediately by compression header byte 0x10 (or 0x11), strip the 4-byte "LZ77" tag and run Nintendo LZ10/LZ11 decompression to recover the inner U8 or BNS stream.
  • Uncompressed sound.bin / Missing Optional Assets: Some minimal channels omit sound.bin (setting SoundSize == 0 in IMET) or omit LZ77 compression; always inspect the 4-byte magic at IMD5 + 0x20 before dispatching to LZ77, U8, or BNS decoders.
  • 24-Bit Name Offset Decoding: Remember that Node.NameOffset is an unsigned 24-bit big-endian integer ((b1 << 16) | (b2 << 8) | b3), NOT a 32-bit integer, because byte 0x00 holds NodeType.

5. Step-by-Step Parser Pseudocode

function parse_opening_bnr(data):
    if data[0x40 : 0x44] == b"IMET":
        base = 0x0000
    elif data[0x80 : 0x84] == b"IMET":
        base = 0x0040
    else:
        error("IMET magic not found at 0x40 or 0x80")

    imet_buf = copy(data[base : base + 0x600])
    stored_md5 = copy(imet_buf[0x5F0 : 0x600])
    imet_buf[0x5F0 : 0x600] = bytes(16 zero bytes)
    assert md5(imet_buf) == stored_md5

    titles = []
    for lang in 0..9:
        raw_utf16 = imet_buf[0x05C + lang * 84 : 0x05C + (lang + 1) * 84]
        titles.append(decode_utf16be_until_null(raw_utf16))

    u8_start = base + 0x600
    files = parse_u8(data[u8_start : len(data)])

    for path, blob in files:
        if blob[0x00 : 0x04] == b"IMD5":
            psize = u32be(blob, 0x04)
            inner = blob[0x20 : 0x20 + psize]
            assert md5(inner) == blob[0x10 : 0x20]
            if inner[0x00 : 0x04] == b"LZ77":
                inner = decompress_nintendo_lz(inner[0x04 : len(inner)])
            # inner is now U8 (0x55AA382D) or BNS/RIFF

    return { titles, files }

function parse_u8(u8_bytes):
    assert u32be(u8_bytes, 0x00) == 0x55AA382D
    root_off = u32be(u8_bytes, 0x04)
    total_nodes = u32be(u8_bytes, root_off + 0x08)
    str_table_off = root_off + total_nodes * 12

    stack = []
    out_files = {}
    for idx in 0..(total_nodes - 1):
        while len(stack) > 0 and stack[-1].end_idx == idx:
            stack.pop()

        noff = root_off + idx * 12
        ntype = u8_bytes[noff]
        name_off = (u8_bytes[noff + 1] << 16) | (u8_bytes[noff + 2] << 8) | u8_bytes[noff + 3]
        data_or_parent = u32be(u8_bytes, noff + 4)
        size_or_end    = u32be(u8_bytes, noff + 8)
        name = read_cstr(u8_bytes, str_table_off + name_off)

        prefix = (len(stack) > 0) ? stack[-1].path : ""
        full_path = (idx == 0) ? "" : (prefix + "/" + name)

        if ntype == 0x01:
            stack.append({ path: full_path, end_idx: size_or_end })
        else:
            out_files[full_path] = u8_bytes[data_or_parent : data_or_parent + size_or_end]

    return out_files

6. Provenance & Confidence

Channel Integrity & Asset Scope Note: While the IMET and IMD5 MD5 checks ensure accidental corruption detection, neither is a cryptographic signature; on NAND and optical discs, authenticity is enforced by the outer Ticket/TMD RSA signatures. Inner .brlyt, .brlan, .tpl, and .bns resource formats belong to Nintendo's SDK UI/audio layer and are referenced here only as container payloads.
  • Confirmed Specification: IMET header offsets (including the 0x40 vs. 0x80 offset distinction), MD5 zeroing rule, 10-language UTF-16BE table, U8 (0x55AA382D) node layout and DFS directory bounds, and IMD5 / LZ77 wrapping are confirmed across retail Wii disc banners and System Menu channels.
  • Undocumented / Reserved Fields: IMET Flags (B + 0x058) and the 588-byte padding region (B + 0x3A4..0x5EF) are zeroed in standard retail titles and remain reserved.
