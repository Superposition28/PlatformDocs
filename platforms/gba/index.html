Game Boy Advance (AGB) Architecture & Platform Formats

Platform Overview · Nintendo Game Boy Advance (ARM7TDMI)

The Game Boy Advance (hardware model AGB) is a 32-bit handheld built around an ARM7TDMI CPU (ARMv4T instruction set, supporting 32-bit ARM and 16-bit Thumb states) clocked at 16.777216 MHz (2^24 Hz). System buses are little-endian across CPU memory, Game Pak ROM/backup windows, and built-in BIOS decompression streams.

CPU Core
ARM7TDMI (ARMv4T, 32-bit ARM / 16-bit Thumb) @ 16.777216 MHz
Endianness
Little-Endian (32-bit/16-bit/8-bit data paths; certain BIOS compression tokens pack big-endian 16-bit bitfields)
Boot Targets
Game Pak ROM at 0x08000000 (cartridge boot) or EWRAM at 0x02000000 (Multiboot / JoyBus)
BIOS ROM
16 KiB internal system ROM at 0x00000000–0x00003FFF providing boot verification, Multiboot, and SWI decompression

Physical Memory Map

The ARM7TDMI has no MMU; all addresses are physical 32-bit addresses. Bus widths and waitstates vary sharply across regions, making IWRAM (32-bit, 0-wait) critical for ARM code and interrupt handlers, while EWRAM and Game Pak ROM share 16-bit buses.

Game Boy Advance Memory Regions (32-Bit Physical Address Space)
Address Range Size Bus Width Default Waitstates Region & Platform Role
0x00000000–0x00003FFF 16 KiB 32-bit 0 System ROM (BIOS): Boot verification, SWI handlers, IRQ entry stub. Read-protected when PC ≥ 0x04000000.
0x02000000–0x0203FFFF 256 KiB 16-bit 2 (3 cycles/16-bit) On-Board WRAM (EWRAM): External work RAM; primary load target for Multiboot images (mirrored every 0x40000 bytes up to 0x02FFFFFF).
0x03000000–0x03007FFF 32 KiB 32-bit 0 (1 cycle) On-Chip WRAM (IWRAM): Fast internal RAM; holds BIOS/user stacks and IRQ vector pointer at 0x03007FFC (mirrored every 0x8000 up to 0x03FFFFFF).
0x04000000–0x040003FE ~1 KiB 16/32-bit 0 I/O Registers: LCD, Sound, DMA, Timers, SIO/Link, Keypad, Interrupts, and Waitstate Control (WAITCNT at 0x04000204).
0x05000000–0x050003FF 1 KiB 16-bit 0 (+1 on 32-bit) Palette RAM: 512 bytes BG palette + 512 bytes OBJ palette (15-bit RGB555 entries).
0x06000000–0x06017FFF 96 KiB 16-bit 0 (+1 on 32-bit) VRAM: Tile/bitmap/map video memory. Does not support 8-bit byte writes (8-bit writes duplicate the byte across the halfword).
0x07000000–0x070003FF 1 KiB 32-bit 0 OAM: 128 object attribute entries (8 bytes each) interleaved with 32 affine matrices.
0x08000000–0x09FFFFFF 32 MiB 16-bit 4 N / 2 S (default) Game Pak ROM (Wait State 0): Primary cartridge ROM mapping. Sequentially incremented addresses use S-cycles.
0x0A000000–0x0BFFFFFF 32 MiB 16-bit 4 N / 4 S (default) Game Pak ROM (Wait State 1): Hardware mirror of cartridge ROM with independent WS1 timing bits.
0x0C000000–0x0DFFFFFF 32 MiB 16-bit 4 N / 8 S (default) Game Pak ROM (Wait State 2) / EEPROM: Hardware mirror of cartridge ROM; upper region (0x0D000000–0x0DFFFFFF, or 0x0DFFFF00–0x0DFFFFFF for >16 MiB ROMs) maps serial EEPROM when present.
0x0E000000–0x0E00FFFF 64 KiB 8-bit 4 (default) Game Pak SRAM / Flash: 8-bit external backup bus. 64 KiB direct window; 128 KiB Flash uses bank-switching commands.

ROM Mapping & WAITCNT (0x04000204) Timings

Game Pak ROM is presented as a single contiguous 32 MiB aperture mirrored across three waitstate windows (WS0 at 0x08000000, WS1 at 0x0A000000, WS2 at 0x0C000000). On power-up, REG_WAITCNT (0x04000204, u16le) initializes to 0x0000. Actual bus access duration is 1 + waitstates CPU cycles per 16-bit halfword (32-bit reads issue two consecutive 16-bit accesses: one non-sequential N-cycle plus one sequential S-cycle).

REG_WAITCNT (0x04000204, u16le) Bitfields
Bits Width Type Field Encoded Values & Semantics
0..1 2 bits u16le SRAM Wait Control 0 = 4, 1 = 3, 2 = 2, 3 = 8 wait cycles (8 cycles recommended for SRAM/Flash).
2..3 2 bits u16le WS0 First Access (N) Wait cycles for first access in 0x08000000: 0 = 4, 1 = 3, 2 = 2, 3 = 8.
4 1 bit u16le WS0 Second Access (S) Sequential wait cycles in 0x08000000: 0 = 2, 1 = 1.
5..6 2 bits u16le WS1 First Access (N) Wait cycles for first access in 0x0A000000: 0 = 4, 1 = 3, 2 = 2, 3 = 8.
7 1 bit u16le WS1 Second Access (S) Sequential wait cycles in 0x0A000000: 0 = 4, 1 = 1.
8..9 2 bits u16le WS2 First Access (N) Wait cycles for first access in 0x0C000000: 0 = 4, 1 = 3, 2 = 2, 3 = 8.
10 1 bit u16le WS2 Second Access (S) Sequential wait cycles in 0x0C000000: 0 = 8, 1 = 1.
11..12 2 bits u16le PHI Terminal Output Cartridge pin clock output: 0 = Disable, 1 = 4.19 MHz, 2 = 8.38 MHz, 3 = 16.78 MHz.
13 1 bit u16le Reserved Unused (write 0).
14 1 bit u16le Game Pak Prefetch Buffer 0 = Disable, 1 = Enable 8-halfword ROM instruction prefetch FIFO when CPU is not accessing Game Pak bus.
15 1 bit u16le Game Pak Type Flag Read-only hardware pin status: 0 = GBA cartridge, 1 = CGB cartridge (IN35 grounded).

BIOS Boot & Execution Dispatch

On cold reset, the ARM7TDMI executes from the internal BIOS at 0x00000000. The BIOS initializes registers, plays the boot logo sequence, and selects a boot target according to hardware state and link activity:

  • Cartridge Boot (0x08000000): If a cartridge is present (and START+SELECT is not held to force slave download), the BIOS validates the 156-byte Nintendo Logo at 0x08000004–0x0800009F, verifies fixed byte 0x080000B2 == 0x96, and checks the complement checksum at 0x080000BD over 0x0A0..0x0BC. On success, it clears memory/registers and branches to 0x08000000.
  • Multiboot / JoyBus Boot (0x02000000): If no valid cartridge boots (or the user forces download mode), the BIOS listens on the serial link port for either Link Cable Multiboot (Normal/MultiPlay) or JoyBus packets, writes the received image to EWRAM starting at 0x02000000, validates the header and transfer CRC16, stamps boot mode/client ID into 0x020000C4–0x020000C5, and branches to 0x020000C0 (Normal/MultiPlay) or 0x020000E0 (JoyBus).
  • Soft Reset (SWI 0x00): Reads the 8-bit flag at 0x03007FFA: zero branches to cartridge ROM 0x08000000; non-zero branches to EWRAM Multiboot entrypoint 0x02000000.
