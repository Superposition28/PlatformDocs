PlayStation 3 (CellOS / PS3)

Platform Overview · 7th Generation Console (2006)

The Sony PlayStation 3 runs CellOS (LV2) beneath the LV1 hypervisor on the heterogeneous Cell Broadband Engine. Retail discs, digital PSN packages, executables, system metadata, and trophy archives share a unified Sony Computer Entertainment (SCE) container ecosystem that is predominantly big-endian, with notable little-endian exceptions such as PARAM.SFO.

Primary CPU
Cell Broadband Engine: 1× 64-bit PowerPC Processing Unit (PPU, big-endian PPC64, 2 hardware threads, VMX/AltiVec) + 6× active Synergistic Processing Units (SPUs, 32-bit big-endian, 256 KiB Local Store each)
Graphics & Memory
RSX Reality Synthesizer GPU · 256 MiB XDR main RAM + 256 MiB GDDR3 VRAM
Operating System
CellOS (LV2 kernel, ELF64 EI_OSABI = 0x66) over LV1 hypervisor; XMB system shell
Distribution Media
Blu-ray Disc (BD-ROM, ISO-9660 / UDF 2.50) and PlayStation Network digital packages (.pkg)
Primary Endianness
Big-endian (BE) for Cell PPU/SPU code, SCE/SELF, PKG, SFB, and TRP; Little-endian (LE) for PARAM.SFO / PARAM.SFX

Hardware & CellOS Runtime Architecture

PlayStation 3 software targets an asymmetric multi-core architecture managed by a privilege-separated hypervisor and kernel stack:

  • PPU (PowerPC Processing Unit): Executes 64-bit big-endian PowerPC binaries (ELFCLASS64, ELFDATA2MSB, EM_PPC64 = 21) compiled with the CellOS LV2 ABI. Although the PPU registers are 64-bit, userland pointers and memory mappings commonly occupy the lower 32-bit address space (4 GiB virtual window) for compactness. Function pointers resolve through OPD (Official Procedure Descriptors) pairing a code entry address with a TOC (r2) base pointer.
  • SPUs (Synergistic Processing Units): Out of 8 physical SPEs, 1 is disabled for manufacturing yield, 1 is reserved by the LV1 hypervisor for security/isolation, and 6 are exposed to userland applications. Each SPU executes standalone 32-bit big-endian SPU ELF modules (EM_SPU = 23) directly out of its private 256 KiB Local Store, transferring main memory via DMA.
  • Dynamic Linking (PRX / SPRX): Shared libraries are packaged as signed PRX relocatable modules (.sprx) whose exported and imported symbols are identified by 32-bit NID (Name ID) hashes rather than ASCII symbol strings at runtime.
  • Security & Encryption Boundary: Executables (EBOOT.BIN, .self, .sprx) and digital packages (.pkg) are wrapped in SCE cryptographic envelopes verified by LV1/LV0/SPU isolated security loaders before ELF segments are mapped into CellOS memory.

PS3_GAME Disc Directory Layout

Standard retail Blu-ray game discs expose an ISO-9660 / UDF filesystem structured around a fixed top-level hierarchy:

Standard PS3 Blu-ray Disc Layout
Path Required Format Role
/PS3_DISC.SFB Yes (Disc) SFB (.SFB) Disc descriptor declaring HYBRID_FLAG, DISC_ID, and disc revision.
/PS3_GAME/PARAM.SFO Yes PSF (\x00PSF) Little-endian title metadata: TITLE_ID, CATEGORY, resolution, audio, parental level, and system flags.
/PS3_GAME/ICON0.PNG Yes PNG (320×176) Primary XMB disc/game icon displayed in the system menu.
/PS3_GAME/PIC0.PNG, PIC1.PNG Optional PNG (up to 1920×1080) XMB foreground overlay (PIC0.PNG) and full-screen background wallpaper (PIC1.PNG).
/PS3_GAME/ICON1.PAM, SND0.AT3 Optional PAM / ATRAC3 Animated XMB icon video stream and background preview audio track.
/PS3_GAME/LICDIR/LIC.DAT Yes (Disc) PS3LICDA Encrypted/signed disc license descriptor verifying licensed disc title IDs.
/PS3_GAME/TROPDIR/NPWR#####_00/TROPHY.TRP Optional TRP (0xDCA24D00) Trophy archive containing TROPCONF.SFM, localized TROP*.SFM XMLs, and PNG icons.
/PS3_GAME/USRDIR/EBOOT.BIN Yes SELF (SCE\0) Primary signed PPU executable launched by CellOS; sibling *.sprx and title data reside under USRDIR/.
/PS3_UPDATE/PS3UPDAT.PUP Optional PUP (SCEUF) Bundled minimum-required system firmware update package.

XMB & PSN Package Model

Digital titles, patches, DLC, and HDD-installed data bypass the optical disc wrapper and instead install from signed .pkg archives into internal storage under /dev_hdd0/game/<TITLE_ID>/:

  • Root equivalence: An installed PSN package mirrors the contents of PS3_GAME/ directly under /dev_hdd0/game/<TITLE_ID>/ (containing PARAM.SFO, ICON0.PNG, TROPDIR/, and USRDIR/EBOOT.BIN), without PS3_DISC.SFB or PS3_UPDATE/.
  • NPDRM Licensing: Paid PSN executables and .edat/.sdat assets carry an NPDRM control block in their SELF/EDAT header tied to a 36-character CONTENT_ID. At runtime, CellOS resolves the decryption klicensee via a console-bound .rif license (derived from a 16-byte .rap key and act.dat) or a free-license key.
  • Patch & Game Data Overlays: Disc updates install into /dev_hdd0/game/<TITLE_ID>/ with CATEGORY = GD (Game Data) and an updated EBOOT.BIN plus PARAM.SFO / PARAM.SFX specifying APP_VER.
